## Authoritative product constraints

Follow the [shared linked-view contract](../../content/collectible-compendium-and-linked-views.md). Compact checklist marks and expanded location rows are the same stable collectible records and persisted states; world pages, indexes, search and Data Jiminy synchronize both ways. World collection percentages exclude narrative/biography gates. Filters never reduce the denominator.

React offline PWA, local progress/backup/migration, bundled local SLM and per-game Data Jiminy knowledge remain MVP. All specified acquisition planners, commands, challenge modules and achievements remain MVP. Missing production screenshot/map images are the only deferred assets; complete text guidance and media support/testing are not deferred. DDD's visual inspiration is still user-owned and unconfirmed. The app is fully spoilerific: no warnings, hiding or reveal controls. Do not implement Available Now/progress-gate tracking; retain concise text prerequisites.

## Edition boundary

Use shipped HD mechanics with per-platform controls/achievement applicability; the 3DS edition is comparison evidence only. Preserve HD-only breeds, changed AR recipes/chest contents, revised toys, removed StreetPass and in-game trophy replacements. A source saying “KH3D” is not automatically wrong, but must be checked for marked HD differences.

The official [2026 Collection page](https://www.jp.square-enix.com/kingdom/collection/) announces HD2.8 for Switch 2, PS5, Xbox Series X|S and Microsoft Store on Windows on **2026-10-08**. Those are announced/unreleased on this audit date; do not claim build/content parity or make their untested mechanics the verified baseline. The same page lists Steam/Epic versions as available. The [official cloud notice](https://support.jp.square-enix.com/news.php?drt=1781017200&id=19066&la=0&n=2&tag=ab4073e28135a1345b861beefd8b6a2c459e1ed4) ends cloud sales on 2026-06-09 and service on 2027-06-09 (23:59 JST); the shared edition policy should own availability handling.

## Highest-priority remaining work

1. Author and independently verify all 438 HD chest directions/order/access conditions; 387 inspected source rows lack location notes.
2. Build all 78 Special Portal location/forecast/reward records, built-in Battle/Friendship records and seven bonus-objective types.
3. Complete HD recipes, all 54 Spirit boards/edges/dispositions, material sources and every command acquisition route; resolve the Aura Lion coordinate conflict.
4. Verify exact achievement applicability, controller inputs, shop/medal stock, secret unlocks and reward fan-out.
5. Exercise offline progress synchronization, migrations, backup and grounded Data Jiminy answers on the verified records.

These are data/research/engineering tasks, not requests for new scope decisions. Ordinary character-story manifests and manual gameplay/playthroughs are not release gates. The user plays Steam; validate content from sources and test application behavior, initially on Apple browser/iPhone/iPad, with Android follow-up.

Crafting is first-class. Optional opt-in inventory shows recipe ingredients as owned/required (x/y), without requiring inventory entry to use the compendium.
