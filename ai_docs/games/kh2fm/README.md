## Current product contract

Ars Arcanum answers where and how to acquire things. Its green Journal presentation does not require a story walkthrough or every biography update. Compact collectible marks and expanded detail rows share one saved record; world totals contain acquisitions, not plot progress. Apply [linked collectible views](../../content/collectible-compendium-and-linked-views.md), [synthesis/inventory](../../content/synthesis-and-inventory.md), and [testing/content validation](../../testing-and-content-validation.md).

Spoilers are shown directly. There is no Available Now/progress-gate filter; relevant prerequisites stay in the text. Inventory is opt-in, with owned/required ingredient counts when enabled. Steam is the user's game platform. Initial application acceptance targets Apple browsers, iPhone and iPad; Android follows. No user playthrough is a validation gate.

## Important corrections

The trailing-space `Accessories ` tab contains 33 candidates; the old empty-tab claim was wrong. Agrabah treasure 24 is Serenity Gem. Twilight Town's Daylight 23 belongs to Sora in the Other Twilight Town. The 16 Roxas prologue chests need their own scope. Data completion makes the final Proof chest appear; it does not open it. Final Mix's Magnet grant is Luxord, and old Lucky Lucky equipment/Serenity farms are unreliable.

Exact location prose, all staff/shield acquisitions, puzzle assembly solutions, several synthesis conflicts/discount cases and full Gummi/platform tables remain unfinished. These are explicit research tasks, not silent feature deferrals. Only missing production screenshot/map image acquisition is deferred.
