# Product Vision and Scope

## Working vision

Rebuild KH Tools as a fast, mobile-first React PWA that makes Kingdom Hearts reference material easy to search, browse, and use during play, including when an internet connection is unavailable.

This is a working statement, not a finalized product definition.
