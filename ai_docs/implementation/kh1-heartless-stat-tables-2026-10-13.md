# KH1 Heartless combat tables

Presentation-only change. Canonical KH1 source data, values, story conditions, sources, and behavioral instructions are unchanged.

- KH1 enemy stat keys are grouped by their exact original context prefix and five recognized suffixes: HP, Strength, Defense, MP recovery value, EXP.
- Numeric contexts compare in narrow semantic tables with up to three context rows and repeated column headers on each table. Before/after Kairi rescue labels and all Shadow world/encounter variants stay explicit; no phase is inferred for unlabelled world contexts.
- Short narrative values use two-column stat tables. The eight damage multiplier fields use short labelled tables. Long exception values use full-width condition notes so text can flow safely across short leaves rather than being clipped in an indivisible narrow cell.
- Unrecognized facts remain ordinary notes. All ten boss entries currently have only generic facts and are left unchanged. Other games are unchanged.
- Original fonts/colors are retained, with 15px table labels and 17px values. Strength/Defense have visible STR/DEF definitions. MP recovery value keeps its full name.
- Parity coverage: 44 enemies, 10 bosses, 986 facts in total: 475 combat cells, 352 multipliers, 139 remaining enemy facts, and 20 generic boss facts. Numeric zero and narrative exceptions are preserved exactly once.
- Browser regressions check exact rendered values, reachability through every note page, every line of long conditions, phone/short-screen overflow, previous/next controls, and unaffected boss notes. The representative set includes Grand Ghost, Shadow, Gigas Shadow, Darkball, Pink Agaricus, Rare Truffle, White Mushroom, Black Fungus, and Invisible.
