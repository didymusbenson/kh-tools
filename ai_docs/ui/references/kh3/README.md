## Design evidence

The Treasures and Game Records views show dark panels, a geometric diamond border, compact headers, a left index and a larger blue/teal content panel, bright blue selection and a bottom help strip. Treasures uses a chest grid; Game Records uses grouped labels and right-aligned values. Characters, Glossary and Story demonstrate distinct light, green and blue treatments rather than one identical skin for every screen.

These are visual references, not instructions to add narrative tracking, native playtime or new completion denominators. Preserve the existing collectible scope and saved-progress identities. Responsive composition and interactions remain to be specified. Saving these references does not implement or certify a custom journal.
