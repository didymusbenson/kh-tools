Treasures clarification: the supplied image aligns each world label/count with its chest rows in one vertically grouped collection. It does not prove a separate equal-height selectable world index. The selected text is the chest's reward label, in this case a map item; it is not evidence of a map viewer. The new report labels paginated world/detail flows as deliberate app adaptations.

## Original design evidence

The Treasures and Game Records views show dark panels, a geometric diamond border, compact headers, left-side labels/counts and a blue/teal content panel, bright blue selection and a bottom help strip. Treasures aligns world labels/counts to grouped chest rows; Game Records has a category index and right-aligned statistic values. Characters, Glossary and Story demonstrate distinct light, green and blue treatments rather than one identical skin for every screen.

These are visual references, not instructions to add narrative tracking, native playtime or new completion denominators. Preserve the existing collectible scope and saved-progress identities. Responsive composition and interactions are now proposed in the linked research/plan; they are not yet implemented or approved. Saving these references does not implement or certify a custom journal.
