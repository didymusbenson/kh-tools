## Design evidence

The Reports screens show a gray/black outer frame, italic REPORTS header, left binder rings, pale textured pages with ornamental corners, magenta angular tabs, glove selection, and a rounded contextual-help strip. The root uses a dark cover with character artwork; interior lists use pale ruled paper. Help uses a distinct cyan/violet menu treatment, separate from Reports.

These are visual references, not instructions to add narrative tracking, native playtime or new completion denominators. Preserve the existing collectible scope and saved-progress identities. Responsive composition and interactions remain to be specified. Saving these references does not implement or certify a custom journal.
